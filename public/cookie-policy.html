Cookie Policy

Last updated: 29 July 2026

Summary

AeroPrompter does not set tracking, advertising, or analytics cookies. The app uses browser storage to provide core teleprompter functionality, save your scripts and settings locally, and make the app load reliably. Visits are counted using our own software on our own server in the European Union, which sets no cookie and stores no identifier on your device.

Technologies Used

Local storage

AeroPrompter stores scripts, the active script ID, and settings such as colourblind mode in your browser's local storage. This is functional storage and is needed for the app to remember your work between visits.

Service worker and cache storage

The app registers a service worker and stores app files such as HTML, CSS, JavaScript, icons, and images in browser cache storage. This improves loading and allows the app shell to remain available if the network is unreliable.

Microphone permission

If you use voice-activated scrolling, your browser may remember your microphone permission choice. This permission is managed by your browser or operating system, not by an AeroPrompter cookie.

Visitor counting

When a page loads, AeroPrompter sends a single message to its own server containing the page path and, where applicable, the host name of the site you arrived from. This uses no cookie and stores nothing on your device. The server counts the visit using a value that changes every day and cannot be traced back to you, and it does not store your IP address. If your browser sends a Do Not Track or Global Privacy Control signal, nothing is sent.

Fonts

Fonts are served from AeroPrompter's own server. No external font or content delivery provider is contacted, so no request data is disclosed to third parties.

Feedback form

The feedback form sends the information you enter to the website server and then to the email delivery provider. AeroPrompter does not use cookies to send feedback.

Managing Storage

You can delete AeroPrompter's local storage, cache storage, and permissions through your browser's site settings. Clearing site data will remove scripts and preferences stored in the browser, so export any scripts you want to keep before clearing data.

Changes

If AeroPrompter later adds advertising, third-party analytics, or other non-essential cookies, this policy should be updated and appropriate choices should be provided before those technologies are activated where required.
